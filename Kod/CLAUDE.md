# CLAUDE.md — JustImagAIne website

Static site (plain HTML + one shared stylesheet), deployed on Netlify from this `Kod/` folder.
The goal of the design is to look hand-made by a person, not generated by AI. Keep it that way.

## Structure
- Every page links `styles.css` (all styles) and `site.js` (mobile menu, tabs, ROI calculator, contact form).
- No inline `<style>` blocks, no Tailwind, no per-page CSS. Add new styles to `styles.css`.
- Each page exists in Czech and English: `x.html` + `x-english.html`. Homepages are `domu.html` (CZ, served at `/cz`) and `index.html` (EN, `/`). Any content or layout change must be made in both.
- Clean URLs (`/ai-chatbot`, `/reference-english`, …) come from `netlify.toml`. When adding a page, add its redirect there.
- Contact forms are Netlify forms (`name="kontakt"` on CZ, `name="contact"` on EN). Keep the `netlify` attribute and the hidden `form-name` input.
- Client logos live in `Assets/clients/`. They are shown in one muted colour via CSS (`filter: brightness(0)` + opacity), never in their own colours side by side.

## Design system
- **Fonts:** Newsreader (serif) for headings `h1–h3`, Inter for everything else. Loaded from Google Fonts in each page `<head>`.
- **Colours** (CSS variables in `styles.css`): paper `#FBFAF7` background, ink `#1B1A17` text, warm brown-grey `#54493F` secondary text, line `#E4DFD4`, sand `#F2EEE6` panels, one accent `#D4521C`.
- **Accent use:** sparingly — the italic second line of a hero headline (`<h1>… <span>…</span></h1>`), one italic word per section heading (`<h2>… <em>word</em> …</h2>`), small labels, numbers. Never on large backgrounds.
- **Layout:** sections separated by thin lines and whitespace; lists and numbered rows instead of cards. Hero = headline left, text + buttons right (`.hero-grid`).
- **Buttons:** `.btn` (dark) and `.btn .btn--ghost` (outlined). Radius 6px.

## Never use (these make a site look AI-generated)
- Gradients (text or background), glows, blurred colour blobs, neon shadows.
- Emoji as icons, pill badges with a dot ("● AI Agency"), coloured left-border cards.
- Grids of identical rounded cards with icons; "1 · 2 · 3" step circles.
- Default fonts like Bricolage Grotesque, Space Grotesk, Poppins for headings; Tailwind default colours (indigo/violet/blue-600).
- Reveal-on-scroll animations everywhere, `transition: all`.
- Stock photos or AI-generated illustrations.

## Checking changes
- Look at the rendered page, not just the code: desktop (1440 and 1920 px wide) and mobile (390 px). No horizontal scroll on mobile.
- Internal links use clean URLs, so check them on a local server that applies the `netlify.toml` redirects (a `file://` URL will not resolve `/ai-chatbot`).
